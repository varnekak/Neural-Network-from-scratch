# Neural Network From Scratch (NumPy Only)

A simple neural network implementation built completely from scratch using **Python**, **NumPy**, and basic math — without using deep learning frameworks like TensorFlow or PyTorch.

This project was created as part of my learning process while following this video:
Building a Neural Network FROM SCRATCH (No TensorFlow/PyTorch)  by  Samson Zhang



---

## What I Learned

- How neural networks work internally
- Forward propagation
- Backpropagation basics
- Activation functions
- Gradient descent
- Matrix operations with NumPy
- Building ML models without external frameworks

---

## Tech Stack

- Python
- NumPy

---

## Features

- Neural network built fully from scratch
- No TensorFlow or PyTorch
- Uses only NumPy and math
- Beginner-friendly implementation
- Educational project for understanding deep learning fundamentals

---

## Purpose

The purpose of this project is to better understand how neural networks work under the hood instead of relying on high-level machine learning libraries.

This is mainly a learning project and not meant for production use.
